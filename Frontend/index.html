Solution.java (Challenge #42 TwoSum)
OpenJDK 17 Sandbox 
public class Solution {
    public int[] twoSum(int[] nums, int target) {
        Map<Integer, Integer> map = new HashMap<>();
        for (int i = 0; i < nums.length; i++) {
            int diff = target - nums[i];
            if (map.containsKey(diff)) return new int[] { map.get(diff), i };
            map.put(nums[i], i);
        }
        return new int[] {};
    }
}

Architecture Distribuée

Une architecture scalable en microservices

Conçue pour isoler les traitements intensifs (compilation de code) des services de consultation et de gestion des identités.

Sécurité & Rôles RBAC

Tokens JWT signés, mot de passe oublié sécurisé, OAuth Google/GitHub et redirection intelligente par rôle.

Bases de Données Découplées

PostgreSQL pour l'intégrité transactionnelle stricte, MongoDB pour les profils et Redis pour les files de traitement en mémoire.

Communications Événementielles

Architecture asynchrone par messages pour garantir la disponibilité du système même lors de pics de soumission de code.
